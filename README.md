# 📸 Photography Website Sidebar Menu

A stylish photography website interface featuring a sliding sidebar navigation menu, a full-screen background image, and interactive hover effects. Built using HTML and CSS.

## 📌 About the Project

This is a mini front-end web development project designed to practice HTML and CSS. The website features a photography-themed background with a transparent sidebar menu that slides into view when the hamburger icon is clicked.

The sidebar includes navigation links, Font Awesome icons, and social media icons, creating a clean and attractive user interface.

## ✨ Features

- **Sliding Sidebar Menu:** Opens and closes using hamburger and cross icons.
- **Full-Screen Background:** Uses a photography background image with `background-size: cover`.
- **Transparent Sidebar:** Styled with a translucent white background and a subtle shadow.
- **Smooth Transitions:** CSS transitions create smooth sidebar movement and hover effects.
- **Interactive Hover Effects:** Menu items display a shadow on hover.
- **Social Media Icons:** Includes Facebook, Twitter, Instagram, and YouTube.
- **Font Awesome Icons:** Adds icons to navigation items and menu controls.
- **Poppins Font:** Uses Google Fonts for typography.
- **No JavaScript Required:** Sidebar toggle functionality is implemented using HTML checkbox inputs and CSS.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome 6.4.0
- Google Fonts (Poppins)

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in your preferred code editor.
3. Ensure that `index.html`, `style.css`, and `photo.jpg` are in the same directory.
4. Open `index.html` in your web browser.
5. Click the hamburger icon to open the sidebar.
6. Click the cross icon to close the sidebar.
